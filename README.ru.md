# Claude Exporter (Firefox)

Расширение для Firefox: экспорт из Claude на ваш компьютер — в Markdown и PDF. Всё работает локально в браузере, данные никуда не отправляются.

## Что умеет

| Вкладка | Что экспортирует |
|---|---|
| **Чаты** | все / за период / выбранные галочками → Markdown и/или PDF; артефакты отдельными файлами; thinking, вызовы инструментов, YAML-метаданные — по желанию |
| **Артефакты** | только артефакты выбранных чатов (все версии, вложения), а также **все артефакты со страницы claude.ai/artifacts** |
| **Проекты** | инструкции, файлы знаний (текст) и файлы проекта (PDF, картинки) |
| **Память и скиллы** | список скиллов с описаниями и текст/настройки памяти claude.ai |
| **Claude Code и файлы** | сессии Claude Code из `~/.claude` (в Markdown/PDF, файлы из `Write`/`Edit` — как артефакты), память, скиллы, `CLAUDE.md`, agents, commands; официальный экспорт claude.ai (ZIP) |
| **Popup** (иконка на панели) | «Экспортировать этот чат», выбор из 5 последних чатов (обновляются на лету), кнопка «Полный экспорт» |

Интерфейс на английском (по умолчанию) и русском: **Настройки → Язык** на странице полного экспорта.

Результат — один ZIP или отдельные файлы в `Загрузки/ClaudeExport/…` (папку можно поменять; для ZIP есть «спрашивать место сохранения»).

## Установка

### Быстро (временно, до перезапуска Firefox)
1. `about:debugging#/runtime/this-firefox` → **Загрузить временное дополнение…**
2. Выберите `claude-exporter-x.y.z.xpi` (или `manifest.json` из папки проекта).
3. Откройте claude.ai и войдите в аккаунт. Иконка расширения → **Открыть полный экспорт**. При первом запуске нажмите «Разрешить доступ к claude.ai».

### Постоянно
См. [docs/INSTALL.md](docs/INSTALL.md): подпись через AMO (`npm run sign`, канал *unlisted*) или Firefox Developer Edition / Nightly / ESR.

## Приватность

* Запросы идут только на `https://claude.ai/*`, из вкладки claude.ai, с вашей сессией. Никаких серверов, аналитики и внешних скриптов: все библиотеки лежат в `vendor/`.
* Расширение читает папку `.claude` только после того, как вы её выбрали, и только сессии, память, скиллы, `CLAUDE.md`, agents, commands, rules. Файлы `.credentials.json`, `settings*.json`, `history.jsonl`, кэши и плагины **не читаются никогда** (проверяется тестом).
* Разрешения: `downloads` (сохранить файлы), `storage` (настройки), `tabs` (найти вкладку claude.ai и текущий чат), `webRequest` (только запись адресов запросов claude.ai во время диагностики; заголовки — только имена), доступ к `https://claude.ai/*`.

## Диагностика

Блок **Диагностика** на странице полного экспорта проверяет все используемые адреса и сохраняет отчёт `Загрузки/ClaudeExport/diagnostics-….json` (только структура, без текста сообщений, id и почты). Кнопка **Начать запись** → открыть нужные страницы claude.ai → **Остановить и проанализировать** находит новые адреса. Описание известных адресов: [docs/api-notes.md](docs/api-notes.md).

Если после обновления claude.ai что-то перестало экспортироваться — запустите диагностику и приложите отчёт.

## Ограничения

* Внутренний API claude.ai не документирован и может измениться.
* Содержимое файлов скиллов и памяти нового режима («melange») сейчас недоступно через известные адреса; экспортируются описания скиллов и текст памяти (если он есть). Локальные скиллы и память Claude Code — со вкладки «Claude Code и файлы».
* Firefox сохраняет файлы только внутрь папки «Загрузки». Другое место — «Спрашивать место сохранения» (только ZIP) или смена папки загрузок в настройках Firefox.
* Экспорт из popup идёт, пока popup открыт (не кликайте мимо, пока идёт PDF или несколько чатов).
* Windows Explorer не открывает ZIP с путями длиннее ~260 байт: длинные названия автоматически сокращаются (полные названия остаются внутри файлов и в `index.md`).

## Разработка

```bash
npm install
npm start        # Firefox с расширением и отдельным профилем (.ff-dev-profile)
npm test         # ~140 тестов: логика, UI в jsdom, Windows-проверка ZIP
npm run lint     # web-ext lint
npm run build    # web-ext-artifacts/claude_exporter-<версия>.zip
npm run sign     # подписанный .xpi (нужны WEB_EXT_API_KEY / WEB_EXT_API_SECRET)
npm run verify   # проверка того, что расширение записало в Загрузки/ClaudeExport
```

Структура:

```
manifest.json, background.js        MV3, запись адресов для диагностики
content/api-client.js               запросы к claude.ai из вкладки (единственное место доступа к API)
popup/, export/                     интерфейс
src/core/                           чистая логика (без browser.*): нормализация, Markdown/PDF, экспорты, парсеры
src/io/                             мост к вкладке, скачивание, ZIP, ленивая загрузка библиотек
vendor/                             JSZip, pdfmake (+Roboto), marked
tests/                              node:test; tests/ui — реальные страницы в jsdom; tests/e2e — проверка файлов на диске
docs/                               api-notes.md, INSTALL.md, E2E-CLAUDE-DESKTOP.md
```

Тест на Windows-открываемость ZIP запускает `Shell.Application` (тот же движок, что у проводника); на других системах он пропускается.
Чек-лист сквозной проверки для Claude Desktop (режим Dispatch): [docs/E2E-CLAUDE-DESKTOP.md](docs/E2E-CLAUDE-DESKTOP.md).
